# Documentation Map

This directory is organized by purpose so the active process, historical context, and review
artifacts are easy to find.

## Structure

- [`process/`](process/README.md): current operating guides for the Agentic Development Life Cycle,
  acceptance, Definition of Done, and regression-testing strategy.
- [`evolution/`](evolution/README.md): versioned evolution plans for roadmap changes, workflow
  changes, and larger technical transitions.
- [`history/`](history/README.md): historical feature specifications created before the current
  Spec Kit flow became the source of truth.
- [`review/`](review/README.md): architecture notes, traceability matrices, and evaluation artifacts.

## Source of Truth Rules

- New feature specifications live under [`specs/`](../specs/README.md).
- Active Copilot and Spec Kit templates live under [`.specify/templates/`](../.specify/templates/).
- The legacy docs template was removed to avoid divergence from the versioned Spec Kit templates.
