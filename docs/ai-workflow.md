# AI Workflow

This repository is intentionally spec-first.

## Rules

1. Start every feature with a short spec.
2. Write acceptance criteria before implementation.
3. Keep the implementation slice small enough to review quickly.
4. Use AI to draft, not to skip validation.

## Suggested flow

1. Open or create an issue.
2. Draft the spec.
3. Define the acceptance checklist.
4. Implement one small slice.
5. Validate against the checklist.
