# Historical Documentation

This directory preserves artifacts that predate the current Spec Kit source-of-truth model.

## Contents

- [`feature-specs/`](feature-specs/): earlier feature specifications kept for traceability and
  historical context.

## Usage

- Do not create new active feature specs here.
- Reference these files when reviewing the origin of an implemented capability or an old decision.
- Create all new feature specs under [`specs/`](../../specs/README.md).
