# controle-financeiro

Setup inicial de um app de controle financeiro pessoal com workflow orientado à IA.

## Objetivo deste estágio

- Definir a base do projeto.
- Registrar os artefatos de IA e processo.
- Evitar começar a modelagem de dados cedo demais.

## O que já existe

- Estrutura Python básica com entrada Streamlit.
- README inicial com escopo do setup.
- Templates e guias para trabalhar com IA e SDD.

## Próximos passos

1. Fechar o setup inicial.
2. Criar a primeira spec guiada por IA.
3. Só então iniciar a modelagem de dados e as primeiras regras de negócio.

## Execução

```bash
pip install -e ".[dev]"
streamlit run streamlit_app.py
```

## Estrutura prevista

- `docs/` para especificações e guias.
- `.github/` para templates de issue e PR.
- `src/controle_financeiro/` para o app.
