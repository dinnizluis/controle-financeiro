# Evolution Plans

This directory stores versioned evolution plans that complement feature-by-feature specifications.

Use it for larger product or technical transitions that span multiple features, for example:

- roadmap increments;
- architecture evolution;
- data migration strategy across releases;
- workflow changes in the ADLC itself.

Create dated files using the same convention documented in
[docs/evolution/README.md](../../docs/evolution/README.md).
