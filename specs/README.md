# Feature Specifications

Each new feature receives a directory named `<number>-<feature>` created by
`/speckit.specify`. Its `spec.md` defines the intended behavior; `plan.md` and
`tasks.md` are the derived implementation artifacts.

Use the flow described in [AI Workflow](../docs/process/ai-workflow.md). Existing files in
`docs/history/feature-specs/` are historical specifications and remain unchanged.

For larger cross-feature roadmaps or technical transitions, use
[`specs/evolution/`](evolution/README.md) together with the operational guidance in
[`docs/evolution/README.md`](../docs/evolution/README.md).
